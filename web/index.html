OCS 题库配置生成器

填好钥匙和模型，右边就是可以直接粘进 OCS 的配置。不联网也能用，只有「真实测试」需要本地小服务。

1. 钥匙与模型

去 opencode.ai/console → Account → Personal API keys 拿，需要先订阅 Go。钥匙只会在你点「真实测试」时发出去。

2. 参数

模型自己觉得没把握时会给低分，低于这条线就放弃作答，让 OCS 显示「未找到」，而不是瞎填一个。调成 0 就是有答案必填。

OpenCode 要求每个请求带一个固定 ID，随便填，只影响路由和缓存。

3. 配置


      

        
        
        
      

      
复制后打开 OCS 设置，找到「题库配置」那个能贴 JSON 的框，整段粘进去保存。

    

  


  

    
离线自检 不用联网

    
造一道题、编一段「模型会返回什么」，看看这份配置怎么解析，以及 OCS 最后会点中哪个选项。这段逻辑和 OCS 里跑的是同一套。

    

      
      
    

    
        

      
      Ctrl / ⌘ + Enter
    

    

  


  

    
真实测试 需要本地小服务

    

      

        浏览器直接请求 opencode.ai 会被跨域拦下来（对方没开 CORS），所以真实测试要起一个本地小服务做转发：
      

      
node serve.mjs

      
然后打开 http://127.0.0.1:8787。你现在是直接打开的这个文件，所以测试按钮先关着。

    

    

      
拿上面那道题，真的问一次模型，看它给你什么、用了多久。

      

        
        
      

      

    

  


  

    配置结构、解析逻辑、答案匹配算法都来自仓库里的同一份源码，不是这里另写的一份。
